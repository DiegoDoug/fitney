# Comparative taste regressions

Run each scenario against the baseline and candidate skill. Compare rendered artifacts where the environment permits; specifications alone cannot establish visual improvement.

## REG-1 — High-frequency mobile utility

Design a workout logging screen for an athlete using one hand between sets. The brand requests monochrome neomorphism, while the task requires fast scanning, reliable disabled/loading states, and readable outdoor use.

Expected pressure: preserve the requested quality without allowing low contrast, ambiguous affordances, or decorative depth to slow logging.

## REG-2 — Dense enterprise investigation

Design a desktop security-events workspace used by analysts for hours. It must support triage, comparison, keyboard operation, and evidence review without becoming a generic card dashboard.

Expected pressure: information density and focus management outrank ornamental spaciousness; distinction should reinforce investigation.

## REG-3 — Native iPad coaching tool

Design an iPad session workspace for a track coach reviewing video, notes, athletes, and planned drills. It should feel native and work with touch, keyboard, pointer, landscape, and split view.

Expected pressure: adaptive Apple patterns and preserved context, not a scaled phone layout or Apple-inspired web imitation.

## REG-4 — Expressive public experience

Design a campaign microsite for an experimental music festival. The experience may be art-directed and kinetic but still needs ticket discovery, schedule comprehension, accessibility, and reduced-motion behavior.

Expected pressure: strong expression with a restraint rule and accessible task path.

## REG-5 — Existing system continuity

Add a complex comparison view to a mature SaaS product whose accepted Design Memory specifies compact density, square geometry, semantic color restraint, and keyboard-first behavior.

Expected pressure: reuse memory, identify any necessary exception, and avoid stylistic drift.
