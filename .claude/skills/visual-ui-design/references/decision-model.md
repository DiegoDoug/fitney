# Adaptive decision model

Score pressures as high, medium, or low: speed/repetition, discoverability, comparison, immersion, consequence, touch ergonomics, environmental readability, accessibility/text scaling, brand expression, platform familiarity, and feasibility.

| Signal | Likely response | Watch for |
|---|---|---|
| Expert repetitive workflow | Higher density, stable placement, shortcuts | Adequate hit areas |
| Novice or infrequent use | Progressive disclosure, explicit labels | Hidden primary actions |
| Outdoor/mobile use | Strong contrast, larger controls | Glare and reach |
| High-consequence action | Confirmation and state clarity | Ambiguous icon-only actions |
| Visual/content browsing | Image dominance, lighter chrome | Lost metadata/navigation |
| Dense comparison | Alignment, tabular rhythm | Card fragmentation |
| Strong brand need | Custom type/color/surfaces | Broken semantics |
| Accessibility priority | Scalable type, focus, redundancy | Color-only meaning |

Choose platform system independently of visual direction. Select a small set of dominant principles. Define semantic type, color, spacing, surface, icon, and motion roles before raw values.

When an aesthetic request conflicts with requirements: name the collision, preserve the intended quality rather than the literal technique, recommend a resolution, and record the tradeoff. Preserve “minimal” in monitoring through alignment and restrained color, not by removing required metrics.
