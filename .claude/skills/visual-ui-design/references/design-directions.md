# Design directions

Combine one primary direction with no more than two supporting qualities.

| Direction | Typical response | Failure mode |
|---|---|---|
| Platform-native | System components, type, motion | Cosmetic imitation |
| Utilitarian | Restrained surfaces, functional hierarchy | Under-signaled actions |
| Data-dense | Alignment, compact rhythm | Tiny targets, card fragmentation |
| Content-first | Content dominance, reduced chrome | Weak navigation/metadata |
| Editorial | Typographic pacing | Novelty replacing scanability |
| Immersive | Edge-to-edge canvas, contextual controls | Hidden critical controls |
| Playful | Expressive color, shape, motion | Noise and inaccessible motion |
| Enterprise | Predictability, structured density | Generic blue-sidebar syndrome |
| Brand-forward | Distinctive type/color/imagery | Brand overriding semantics |
| Premium | Precision and restraint | Black/gold cliché, low contrast |

Glass, gradients, shadows, rounding, brutalist borders, and monochrome are subordinate techniques.
