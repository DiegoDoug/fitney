# Selectable visual principles

Use these as decision lenses, not a universal checklist.

| Principle | Emphasize when | UI implication |
|---|---|---|
| Hierarchy | Tasks/content compete | Clear emphasis levels |
| Density | Experts compare/repeat | Compact rhythm, adequate targets |
| Readability | Long text, glare, fatigue | Measure, line height, scaling |
| Contrast | Outdoor use or monitoring | Strong separation, redundant cues |
| Proximity | Related data scans together | Group spacing before containers |
| Alignment | Comparison/forms/tools | Shared baselines and columns |
| Consistency | Repeated workflows | Stable semantics and tokens |
| Affordance | Novel controls | Visible cues and labels |
| Feedback | Async/edit/destructive work | Progress, undo, recovery |
| Ergonomics | Touch or mobility | Reach, target size, spacing |
| Progressive disclosure | Complexity exceeds task | Advanced areas and defaults |
| Content priority | Editorial/media/commerce | Reduced chrome, retained metadata |
| Responsive adaptation | Multiple form factors | Reflow by priority |
| Trust and clarity | Finance/health/security | Explicit states and provenance |

Hierarchy is not merely “make it bigger,” premium is not “black and gold,” and native iOS is not “rounded cards plus blur.”
