# Prompt: visual design intake

Use this only for fields that cannot be inferred from supplied artifacts. Ask the smallest useful batch, normally no more than three questions at once.

```text
Before I choose the visual direction, I need the missing decisions that would materially change it:

1. [Primary platform/form factor question]
2. [Primary user/task/environment question]
3. [Brand or compliance-level question]

If you do not have a preference, I can infer a recommendation from the supplied product context and label the assumption.
```

Question bank: product purpose; primary users; most frequent/important actions; environment; platform and device; existing wireframe/layout; brand assets or prohibited treatments; platform-native vs adapted vs inspired; accessibility/compliance; implementation constraints; desired artifact.
