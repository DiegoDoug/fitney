# Prompt: use upstream artifacts

```text
Use /visual-ui-design on the supplied upstream artifacts. Inspect them first, normalize the relevant evidence into the Design Context Profile, and preserve approved research, Experience Read, IA, flows, interaction decisions, and wireframe structure. Ask only for missing information that would materially change the visual system. Produce a Design Read, calibrate the four visual dials, compare coherent candidate theses when the direction is open, and select a product-specific signature move with a restraint rule. Derive the platform system, foundations, component treatment, states, and validation. Clearly label any proposed UX change rather than silently modifying upstream decisions. Deliver [design direction / full UI specification / rendered applied screens], and when rendering is requested perform a critique-and-correction pass before delivery.
```
