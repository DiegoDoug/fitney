# Prompt: redesign an existing product

```text
Use /visual-ui-design to redesign the supplied product, screenshots, or codebase. Separate observable current behavior from inference. Preserve working product architecture unless I explicitly authorize UX restructuring. Identify the Design Read, design pressures, current visual failures, generic-template tells, and product-specific opportunities. Calibrate familiarity, density, expression, and motion; select a justified platform system and visual thesis; define one signature move and a restraint rule; then apply the semantic visual system to the in-scope screens and states. Produce a rendered redesign, critique the first render, correct the most consequential issues, and validate accessibility, responsiveness, and implementability. Explain consequential tradeoffs, not every cosmetic choice.
```
