# Visual UI Specification

## 1. Context and traceability

Design Context Profile, Design Read, assumptions, approved upstream decisions, and pressure-to-response table.

## 2. Direction and platform

Platform system, compliance level, target versions, primary direction, supporting qualities, calibrated dials, signature move, restraint rule, selected principles, rejected candidate, and tradeoffs.

## 3. Foundations

- Semantic type roles and scale
- Semantic color roles and contrast behavior
- Spacing, sizing, radius, border, and elevation roles
- Grid/layout and responsive rules
- Iconography, imagery, and data visualization
- Motion roles and reduced-motion behavior

## 4. Components

For each important component: semantics, anatomy, variants, content, tokens, states, responsive behavior, interaction/accessibility notes, and do/don't guidance.

## 5. Screen application

Apply the system to supplied structures. Cover hierarchy, responsive behavior, and relevant empty/loading/error/offline/permission/success/destructive states.

## 6. Validation and handoff

Rendered artifact locations, critique-and-correction summary, accessibility review, platform review, generic-pattern review, consistency review, known limitations, implementation notes, and acceptance checks.
