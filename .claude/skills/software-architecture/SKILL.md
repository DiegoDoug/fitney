# Software architecture

Read `../../skill-system/lifecycle.md`, `../../skill-system/decision-ownership.md`, `../../skill-system/artifact-standard.md`, and `references/phase-contract.md` before working.

Translate approved product, UX, and visual requirements into the smallest coherent technical structure that satisfies current constraints. Inspect existing code, schemas, interfaces, tests, deployments, and runtime evidence before proposing changes. Prefer evolutionary decisions and explicit tradeoffs over speculative scale.

Create ADRs only for consequential choices. Preserve uncertainty and identify decisions that can be deferred safely.

Produce or update the architecture artifacts, update the roadmap, submit the phase for approval, report one lifecycle status, and stop.
