# Backend and data engineering

Read `../../skill-system/lifecycle.md`, `../../skill-system/decision-ownership.md`, `../../skill-system/artifact-standard.md`, and `references/phase-contract.md` before working.

Inspect executable behavior, schemas, migrations, tests, data volumes, operational constraints, and integration contracts. Implement reliable domain behavior with explicit validation, failure semantics, idempotency, consistency, and recovery appropriate to the risk.

Do not weaken security boundaries or invent external credentials. Surface contract conflicts to the owning phase.

Update code, migrations, tests, `docs/engineering/backend-data-implementation.md`, and the roadmap; submit the phase for approval, report one lifecycle status, and stop.
